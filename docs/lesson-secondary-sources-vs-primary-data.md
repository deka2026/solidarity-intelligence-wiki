# 레슨 — 보도 기반 목록은 원자료 한 장으로 뒤집힌다

> 작성일: 2026-09-25 | 맥락: 통합 전 광주·전남 출연기관 리스트 작업

## 1. 웹 원문이 막히면 "검색 요약"만 남는다 — 그 한계를 문서에 박아둔다

- 클라우드 세션에서 law.go.kr·mois.go.kr·data.go.kr·언론사 페이지가 모두 egress 차단. 쓸 수 있는 건 WebSearch의 **요약문**뿐이었다
- 요약문은 기관명을 일부만 나열하고 수치("전남 21개")만 준다. 목록을 채우려고 여러 검색 결과를 이어붙이면 **누락과 유형 오분류**가 생긴다
- 그래서 1차본 맨 위에 "원문 미확인, 3개 미확인" 경고를 달았다 — 이 경고 덕분에 사용자가 원자료(CSV)를 가져왔다

## 2. 원자료가 오면 덧붙이지 말고 교체한다

사용자가 준 전국 지방공공기관 목록 CSV(2024.7.31.)로 대조하니 1차본은:

| 1차본(보도 기반) | 원자료 |
|---|---|
| 전남 출연기관 14개 확인 + 3개 미확인 | **22개** — 박람회·대회 조직위원회 등 보도에 안 나오는 기관이 다수 |
| 남도장터 = 주식회사(출자) | **재단법인(출연)** — 이름만 보고 추측한 오류 |
| 공동 운영 기관은 "추정" | 기관장 "강기정, 김영록" 표기로 **확정** |

- 교훈: 보도에 나오는 기관은 "통합·평가·채용" 뉴스거리가 있는 기관뿐이다. **보도 빈도 ≠ 기관 목록**
- 원자료가 오면 1차본에 몇 줄 보태지 말고 **원자료를 뼈대로 문서를 다시 쓴다**. 기관명도 원자료 표기 그대로 쓰고, 이후 바뀐 명칭은 별도 열로

## 3. 원자료와 발표 수치가 어긋나면 억지로 맞추지 않는다

- 2024.7. 목록 전남 23개 vs 2026.9. 발표 21개 — 2개 차이를 추측으로 지우지 않고 "기관 수 대조" 절에 **미확인으로 남겼다** ([[lesson-source-attribution-honesty]]와 같은 원칙)
- 원자료의 기준일을 문서 제목 가까이에 박아둔다. 기준일 없는 목록은 틀린 목록과 구별되지 않는다
